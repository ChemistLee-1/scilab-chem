# 단원·성취기준 분류

데이터는 `src/data/curriculum.js`에 있다. 과목 → 대단원(교육과정 영역과 같음) → 중단원(교과서 차례) 구조이고, 시뮬레이션은 `simulations.js`의 `places`(중단원 또는 대단원 id)와 `standards`(성취기준 코드)로 연결한다.

## 과목과 기준 교과서
| 과목 | 구분 | 중단원 기준 |
|---|---|---|
| 통합과학1 Ⅱ. 물질과 규칙성 | 공통 | 동아출판 (1. 원소의 형성 / 2. 자연을 구성하는 원소) |
| 통합과학2 Ⅰ. 변화와 다양성 중 2. 화학 변화 | 공통 | 동아출판 |
| 화학 Ⅰ~Ⅳ | 일반 선택 | 천재교육(임희준), 소단원까지 확인 |
| 물질과 에너지 Ⅰ~Ⅳ | 진로 선택 | 동아출판, Ⅰ만 중단원 확인 |
| 화학 반응의 세계 Ⅰ~Ⅲ | 진로 선택 | 동아출판, Ⅰ·Ⅱ만 중단원 확인 |

## 한계
- 물질과 에너지 Ⅱ~Ⅳ, 화학 반응의 세계 Ⅲ은 중단원을 확인하지 못해 대단원 단위로 분류했다(`sections: []`).
- 비상교육 교과서의 단원명은 반영하지 못했다. 대단원은 교육과정 영역이라 출판사와 관계없이 같다.
- 통합과학의 화학 외 성취기준(생명·지구·물리)은 넣지 않았다.
