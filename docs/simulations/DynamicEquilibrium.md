# 가역 반응과 동적 평형 — `src/simulations/DynamicEquilibrium.jsx`

- 단원: 화학 Ⅲ-1 화학 평형 (01 가역 반응과 화학 평형)
- 성취기준: 12화학03-01
- 데이터: 물 포화 증기압 0.01–120 °C(6-5) `WATER_VP`, 기체 상수 R(1-2)
- 디자인: 사용자 제공 HTML "동적 평형 시뮬레이션 — 증발과 응축"의 내용(플라스크, 증발·응축 속도 그래프, 평형 표시)을 사이트 공통 레이아웃(SimLayout, Slider, Readout, LineChart, ScaleNote)으로 옮김

## 기능
- 반응식 **H₂O(l) ⇌ H₂O(g)**, 마개로 막은 둥근 플라스크
- 온도 20–90 °C, 일시정지, "진공에서 시작", "수증기 많이 넣고 시작"(평형 2배에서 출발 → 반대 방향에서 같은 평형)
- 액체·기체 분자 수, 포화 증기압 P°(CRC), 지금 수증기 압력 P, 증발·응축 속도(상댓값), 수증기 양(mol, mg)
- 시간–반응 속도 그래프(최근 30초): 증발은 수평선, 응축은 0에서 올라와 만남. 만나는 시점에 "동적 평형" 점선
- 색: 액체 분자·응축 = 파랑 `#2f80ed`, 기체 분자·증발 = 주황 `#f2994a`

## 계산·가정
- 포화 증기압: CRC 표를 ln P 기준으로 선형 보간 (VaporPressure 와 같은 방식)
- 플라스크 빈 공간 1 L, 기체 분자 그림 1개 = 2×10⁻⁴ mol → 평형 기체 개수 = P°V/(RT) ÷ 2×10⁻⁴
- 증발·응축 속도 ∝ 압력 ÷ √T (분자 운동론, 헤르츠–크누센). 증발은 P°, 응축은 지금 P 사용. 25 °C 포화 상태 증발 속도 = 1
- 거시 변화: dn/dt = k(n평형 − n), k = 0.2·√(T/298.15) /s (화면용 시간)
- 분자 그림: 수면에 부딪힌 기체 분자가 붙을 확률을 k ÷ (측정한 충돌 빈도)로 맞춰 응축 속도를 거시 값과 일치시킴. 증발은 기체 그림 수가 거시 값 n 을 따라가도록 수면 근처 분자를 띄움 → 평형에서 증발 수 = 응축 수
- 액체 분자 그림 260개는 축척 없음 (실제로는 액체가 수증기보다 수백~수천 배 많음)
- 기체 그림 속력 ∝ √T (25 °C = 200 px/초)
- 평형 판정: 두 속도 차이 2 % 미만이 1초 유지, 5 % 넘으면 해제

## 검증값 (평형에서 기체 그림 수 / 수증기 압력)
