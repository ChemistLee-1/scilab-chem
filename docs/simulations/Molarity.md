# 부피 플라스크로 몰 농도 용액 만들기 — `src/simulations/Molarity.jsx`

- 단원: 화학 Ⅳ-1 물의 자동 이온화와 pH (02 몰농도), 화학 Ⅰ-2 몰과 화학 반응식 (01 몰)
- 성취기준: 12화학04-02 (원하는 몰 농도의 용액을 만들 수 있다), 12화학01-02
- 데이터 (`crc.js`의 `SOLUTES`, 몰질량은 `molarMass` + 원자량 1-11)
  | 용질 | 몰질량 (g/mol) | 고체 밀도 (g/cm³) | 25 °C 용해도 (g / 물 100 g) |
  |---|---|---|---|
  | 염화 나트륨 NaCl | 58.44 | 2.17 (4-89) | 36.0 (4-89) |
  | 황산 구리(Ⅱ) 오수화물 CuSO₄·5H₂O | 249.68 | 2.286 (4-62) | 22.0, 무수물 기준 (4-62) |
  | 포도당 C₆H₁₂O₆ | 180.16 | 1.562, 18 °C (3-282) | 106 (5-172의 15 °C 45.0 %, 30 °C 54.6 % → 25 °C 보간 51.4 %) |

## 기능
- 설정: 용질 3가지, 부피 플라스크 50·100·250 mL, 목표 농도 0.05–0.50 M, 무작위 과제
- 실험대 위 기구를 직접 누르거나(빛나는 기구가 지금 쓸 수 있는 것), 오른쪽 버튼으로 같은 동작을 할 수 있음
- 8단계 절차
  1. 필요한 질량 계산: 학생이 g 을 입력해 확인(±1 %), 또는 풀이 보기 (n = CV, m = nM, 입자 수 = nN<sub>A</sub>)
  2. 질량 측정: 칭량 접시 올리기 → 영점(TARE) → 시약병에서 약숟가락으로 덜어 넣기/덜어 내기 (많이 ≈2 g, 조금 ≈0.2 g, 톡톡 ≈0.02 g, ±40 % 무작위) → 저울 값(0.01 g) 기록
  3. 비커에서 녹이기: 접시 → 비커, 세척병(누르고 있기)으로 물, 유리 막대(누르고 있기)로 젓기. 물이 부족하면 CRC 용해도만큼만 녹고 경고
  4. 플라스크로 옮기기: 깔때기를 꽂아야 부을 수 있음
  5. 비커·유리 막대 헹구기: 헹군 물을 붓는 횟수만큼 남은 용질이 줄어듦. 헹구지 않고 넘어갈 수도 있음
  6. 표선 맞추기: 깔때기를 빼야 함 → 세척병으로 채우고 스포이트(1방울 0.05 mL)로 맞춤. 표선 근처에서 목 확대창(메니스커스와 표선)
  7. 마개 막고 섞기: 마개 없이 뒤집으면 막음. 뒤집을 때마다 섞인 정도 증가
  8. 결과: 실제 몰 농도, 목표와의 차이, 오차 원인(질량, 못 옮긴 용질, 표선 오차, 덜 섞임), 기록한 질량으로 계산한 라벨 농도
- 입자 그림: 녹은 용질은 이온(Na⁺/Cl⁻, Cu²⁺/SO₄²⁻) 또는 분자(포도당) 점으로 표시. 점 1개 = 목표 mol 의 약 1/40 을 1·2·5 단위로 반올림한 양
- 섞기 전에는 처음 부은 진한 용액이 아래쪽에만 있고(색·점), 뒤집어 섞으면 고르게 퍼짐 (CuSO₄ 는 농도에 따라 파란색이 진해짐)

## 계산·가정
- 실제 농도 = 플라스크에 들어간 용질 mol ÷ 플라스크 속 용액 부피
- 용액 부피 = 넣은 물 + 녹은 용질 질량 ÷ 고체 밀도 (섞일 때 부피 변화 무시), 물 1 mL = 1 g
- 녹을 수 있는 최대 질량 x: x·f ≤ s/100 × (W + x(1−f)) (f = 수화물 중 무수물 질량 비율, s = 용해도, W = 물 질량). 수화물의 결정수는 녹으면 용매가 됨
- 부은 뒤 비커 벽·유리 막대에 용액 1.0 mL 가 남음 → 남는 용질 비율 = 1 mL ÷ 비커 용액 부피. 헹굴 때마다 그 비율이 다시 곱해짐
- 부피 플라스크 그림은 크기와 상관없이 같은 모양 (둥근 몸통 + 긴 목). 화면 부피는 폭 함수를 회전체로 적분해 표선 = 플라스크 부피로 맞춤
- 확대창: 목 안지름 가정(50 mL 1.1 cm, 100 mL 1.3 cm, 250 mL 1.5 cm), 1 mm = 5 px
- 표선 허용 오차: A급(ASTM E288) 50 mL ±0.05, 100 mL ±0.08, 250 mL ±0.12 mL
- 세척병 = 플라스크 부피의 1/25 mL/s, 젓기 = 필요 질량의 35 %/s, 뒤집기 1번마다 덜 섞인 정도 × 0.7 (10번 ≈ 97 %) — 모두 화면용

## 검증값
- 0.10 M CuSO₄·5H₂O 100 mL: 0.01000 mol, 2.497 g, 입자 6.02 × 10²¹ 개
- 0.10 M NaCl 250 mL: 1.461 g / 0.50 M 포도당 50 mL: 4.504 g
- 물 약 20 mL 로 녹여 부은 뒤 비커에 남은 용질 4.74 % → 약 4 mL 씩 2번 헹구면 0.53 % → 0.06 %
- 100 mL 플라스크 목에서 1방울(0.05 mL) = 메니스커스 0.38 mm 상승
- 브라우저 확인: 2.49 g, 2번 헹굼, 표선 99.99 mL → 0.0998 M (−0.21 %). 헹구지 않고 표선 1.6 mL 넘김(250 mL) → −3.46 %
