# 부피 플라스크로 몰 농도 용액 만들기 — `src/simulations/Molarity.jsx`

- 단원: 화학 Ⅳ-1 물의 자동 이온화와 pH (02 몰농도), 화학 Ⅰ-2 몰과 화학 반응식 (01 몰)
- 성취기준: 12화학04-02 (원하는 몰 농도의 용액을 만들 수 있다), 12화학01-02
- 데이터 (`crc.js`의 `SOLUTES`, 몰질량은 `molarMass` + 원자량 1-11)
  - 0.01 g 저울로 필요한 질량을 정확히 달 수 있도록 **몰질량이 정수에 가까운 물질**만 사용 (화면 표시는 0.1 g/mol 단위)
  | 용질 | 몰질량 (g/mol, CRC) | 고체 밀도 (g/cm³) | 25 °C 용해도 (g / 물 100 g) |
  |---|---|---|---|
  | 수산화 나트륨 NaOH | 39.997 → 40.0 | 2.13 (4-90) | 100 (4-90) |
  | 탄산수소 나트륨 NaHCO₃ | 84.007 → 84.0 | 2.20 (4-90) | 10.3 (4-90) |
  | 아이오딘화 칼륨 KI | 166.003 → 166.0 | 3.12 (4-83) | 148 (4-83) |
  - 목표 농도는 0.1·0.2·0.5·1.0 M 중 선택 → 50·100·250·1000 mL 와 조합한 48가지 모두 필요한 질량이 0.01 g 단위로 떨어짐 (차이 0.004 g 미만)
  - 1.0 M NaHCO₃ 는 녹이는 데 물이 플라스크 부피의 82 % 이상 필요(거의 포화) → 계산 단계에서 경고 (최소 물 > 플라스크 부피의 60 % 일 때)

## 기능
- 설정: 용질 3가지, 부피 플라스크 50·100·250·1000 mL, 목표 농도 0.1·0.2·0.5·1.0 M, 무작위 과제
- NaOH 는 질량 측정 단계에서 '수분 흡수 → 빠르게 달기, 용해열 → 식힌 뒤 옮기기' 안내
- 실험대 위 기구를 직접 누르거나(빛나는 기구가 지금 쓸 수 있는 것), 오른쪽 버튼으로 같은 동작을 할 수 있음
- 8단계 절차
  1. 필요한 질량 계산: 학생이 g 을 입력해 확인(0.01 g 까지 맞으면 정답), 또는 풀이 보기 (n = CV, m = nM, 입자 수 = nN<sub>A</sub>)
  2. 질량 측정: 칭량 접시 올리기 → 영점(TARE) → 시약병에서 약숟가락으로 덜어 넣기/덜어 내기 (필요 질량이 20 g 넘으면 아주 많이 ≈10 g, 많이 ≈2 g, 조금 ≈0.2 g, 톡톡 ≈0.02 g, ±40 % 무작위) → 저울 값(0.01 g) 기록
  3. 비커에서 녹이기: 접시 → 비커, 세척병(누르고 있기)으로 물, 유리 막대(누르고 있기)로 젓기. 물이 부족하면 CRC 용해도만큼만 녹고 경고
  4. 플라스크로 옮기기: 깔때기를 꽂아야 부을 수 있음
  5. 비커·유리 막대 헹구기: 헹군 물을 붓는 횟수만큼 남은 용질이 줄어듦. 헹구지 않고 넘어갈 수도 있음
  6. 표선 맞추기: 깔때기를 빼야 함 → 세척병으로 채우고 스포이트(1방울 0.05 mL)로 맞춤. 표선 근처에서 목 확대창(메니스커스와 표선)
  7. 마개 막고 섞기: 마개 없이 뒤집으면 막음. 뒤집을 때마다 섞인 정도 증가
  8. 결과: 실제 몰 농도, 목표와의 차이, 오차 원인(질량, 못 옮긴 용질, 표선 오차, 덜 섞임), 기록한 질량으로 계산한 라벨 농도
- 입자 그림: 녹은 용질은 이온(Na⁺/OH⁻, Na⁺/HCO₃⁻, K⁺/I⁻) 점으로 표시. 점 1개 = 목표 mol 의 약 1/40 을 1·2·5 단위로 반올림한 양
- 섞기 전에는 처음 부은 진한 용액의 입자가 아래쪽에만 있고, 뒤집어 섞으면 고르게 퍼짐

## 계산·가정
- 실제 농도 = 플라스크에 들어간 용질 mol ÷ 플라스크 속 용액 부피
- 용액 부피 = 넣은 물 + 녹은 용질 질량 ÷ 고체 밀도 (섞일 때 부피 변화 무시), 물 1 mL = 1 g
- 녹을 수 있는 최대 질량 x: x·f ≤ s/100 × (W + x(1−f)) (f = 수화물 중 무수물 질량 비율, s = 용해도, W = 물 질량). 지금 용질은 모두 무수물(f = 1)이지만 수화물도 계산할 수 있게 남겨 둠
- 부은 뒤 비커 벽·유리 막대에 용액 1.0 mL 가 남음 → 남는 용질 비율 = 1 mL ÷ 비커 용액 부피. 헹굴 때마다 그 비율이 다시 곱해짐
- 부피 플라스크 그림은 크기와 상관없이 같은 모양 (둥근 몸통 + 긴 목). 화면 부피는 폭 함수를 회전체로 적분해 표선 = 플라스크 부피로 맞춤
- 확대창: 목 안지름 가정(50 mL 1.1 cm, 100 mL 1.3 cm, 250 mL 1.5 cm, 1 L 2.1 cm), 1 mm = 5 px
- 표선 허용 오차: A급(ASTM E288) 50 mL ±0.05, 100 mL ±0.08, 250 mL ±0.12, 1 L ±0.30 mL. 1 L 플라스크는 1000 mL 비커와 함께 씀
- 세척병 = 플라스크 부피의 1/25 mL/s (표선 맞추기에서 95 % 이상 차면 최대 4 mL/s), 젓기 = 필요 질량의 35 %/s, 뒤집기 1번마다 덜 섞인 정도 × 0.7 (10번 ≈ 97 %) — 모두 화면용

## 검증값
- 0.1 M NaOH 100 mL: 0.01000 mol, 0.40 g, 입자 6.02 × 10²¹ 개
- 0.5 M NaHCO₃ 250 mL: 10.50 g / 0.2 M KI 50 mL: 1.66 g / 1.0 M NaOH 1 L: 40.00 g / 1.0 M KI 1 L: 166.00 g
- 물 약 20 mL 로 녹여 부은 뒤 비커에 남은 용질 4.74 % → 약 4 mL 씩 2번 헹구면 0.53 % → 0.06 %
- 100 mL 플라스크 목에서 1방울(0.05 mL) = 메니스커스 0.38 mm 상승
- 브라우저 확인: 0.2 M NaOH 50 mL, 저울 0.40 g(실제 0.399 g), 2번 헹굼, 50.03 mL → 0.1977 M (−1.13 %)
