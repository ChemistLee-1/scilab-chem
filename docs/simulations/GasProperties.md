# 기체의 성질과 혼합 기체 — `src/simulations/GasProperties.jsx`

- 단원: 물질과 에너지 Ⅰ-01 기체의 성질, Ⅰ-02 혼합 기체
- 성취기준: 12물에01-01, 12물에01-02
- 데이터: R(1-2), 원자량(1-11), 반데르발스 a·b(6-56) — `GASES` (He, Ne, Ar, N₂, O₂, CO₂)

## 기능
- 기체 A(+ 선택적으로 기체 B 혼합), 양(mmol), 온도(100–600 K), 부피(1–5 L)
- 전체·부분 압력, 몰 분율, 평균 속력 √(3RT/M), 단일 기체일 때 반데르발스 압력 비교, P–V 그래프

## 계산·가정
- P(kPa) = nRT/V (J/L = kPa). 반데르발스는 bar 단위로 계산 후 ×100.
- 입자 1개 = 2 mmol, 속력 = 맥스웰 분포 표본 × 0.25 (화면 1 px/s = 4 m/s), 용기 가로 1 L = 110 px
- 혼합 기체의 반데르발스 보정은 하지 않음

## 검증값
- N₂ 300 K 평균 속력 517 m/s
- 0.1 mol, 300 K, 2.5 L → 99.8 kPa
