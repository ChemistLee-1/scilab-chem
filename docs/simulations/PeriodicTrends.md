# 원소의 주기적 성질 — `src/simulations/PeriodicTrends.jsx`

- 단원: 통합과학1 Ⅱ-2-01 원소의 규칙성 / 화학 Ⅱ-1 화학 결합의 성질
- 성취기준: 10통과1-02-03, 12화학02-02
- 데이터: `ELEMENTS` (crc.js) 1~20번 — 원자량(1-11), 제1 이온화 에너지 eV(1-17), 공유 반지름 Å(9-49), Pauling 전기음성도(9-97)

## 기능
- 주기율표(1~4주기, 1·2·13~18족)에서 원소 선택, 속성(반지름 / 이온화 에너지 / 전기 음성도) 전환, 원자 번호에 따른 그래프

## 계산·가정
- 반지름 원: 1 pm = 0.17 px (실제 크기에 비례)
- 이온화 에너지·전기 음성도 원: 6 px + 값/최댓값 × 26 px (상대 비교)
- 이온화 에너지 kJ/mol = eV × 96.485
- 18족은 전기음성도 값이 없어 표시하지 않음
