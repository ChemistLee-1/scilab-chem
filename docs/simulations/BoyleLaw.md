# 보일 법칙: 압력과 부피 — `src/simulations/BoyleLaw.jsx`

- 단원: 물질과 에너지 Ⅰ-01 기체의 성질
- 성취기준: 12물에01-01
- 데이터: 기체 상수 R(1-2), 표준 대기압 101.325 kPa → R = 0.08206 L·atm/(mol·K)
- 디자인: 사용자 제공 HTML "보일 법칙 시뮬레이션 — 압력과 부피"의 기능(실린더·추·압력계, 기록, 자동 측정, 그래프 3종, 측정 데이터 표, CSV 저장, 실험 방법·한계)을 사이트 공통 레이아웃(SimLayout, Slider, Segmented, Readout, LineChart, ScaleNote)으로 옮김

## 기능
- 외부 압력 0.5–4.0 atm (0.1 단위, ± 버튼), 온도 200–400 K (50 단위), 기체의 양 0.05–0.15 mol
- 읽기: P, V, P×V, nRT(이론값), 피스톤 충돌 횟수(최근 2초 평균)
- [현재 값 기록]: 피스톤이 멈췄을 때만(이론 부피와 0.3 % 이내). 측정 오차(부피 표준편차 0.8 %) 켜고 끄기
- [자동 측정]: 0.5, 1.0 … 4.0 atm 8점, 각 점에서 피스톤이 멈추고 0.35초 뒤 기록 (약 16초)
- 그래프: 부피–압력 / 부피–1/압력(직선 맞춤 기울기·R²) / P×V–압력(평균). 같은 온도·양끼리 같은 색, 빈 원 = 지금 상태
- 측정 데이터 표(행 삭제, 전체 삭제), **CSV 저장**: UTF-8 BOM(엑셀 한글), 열 = 번호, 온도(K), 기체의 양(mol), 압력(atm), 부피(L), 1/압력, 압력×부피. 파일 이름 `boyle_data_YYYYMMDD_HHMM.csv`

## 계산·가정
- 이상 기체 V = nRT/P. 실제 기체 보정 없음
- 입자 그림 수 = 몰수 × 500, 속력 ∝ √T (300 K = 150 px/초), 입자끼리 충돌 생략, 피스톤 충돌은 속력 보존(등온)
- 실린더 0–10 L → 360 px, 추 1개 = 0.5 atm, 피스톤 이동 빠르기는 화면용
- 공통 부품 변경: `Slider`에 `disabled`, `LineChart` 표식에 `hollow`(빈 원) 추가

## 검증값
- 0.10 mol, 300 K: nRT = 2.462 atm·L, 1 atm 에서 V = 2.46 L
- 자동 측정(오차 포함) V–1/P 기울기 2.460 atm·L, R² 0.9999 / 400 K: 3.252 (이론 3.282)
- CSV 첫 3바이트 EF BB BF(BOM) 확인
