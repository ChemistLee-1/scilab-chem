# 묽은 용액의 총괄성 — `src/simulations/Colligative.jsx`

- 단원: 물질과 에너지 Ⅱ 용액의 성질
- 성취기준: 12물에02-02
- 데이터: Kb·Kf(15-27, 15-28), 용매 녹는점·끓는점(3-4~3-246) `SOLVENTS` (물, 벤젠, 사이클로헥세인, 아세트산), 25 °C 물 증기압 3.1699 kPa(6-5)

## 계산·가정
- ΔTb = i·Kb·m, ΔTf = i·Kf·m (묽은 용액 근사)
- 용질: 포도당·요소 i = 1, NaCl i = 2, CaCl₂ i = 3 (완전 해리 가정)
- 물일 때 라울 법칙 증기압 P = x(용매) × 3.1699 kPa
- 용질 입자: 1 mol/kg 당 화학식 12개, 입자 수 = 화학식 수 × i (NaCl → Na⁺ : Cl⁻ = 1 : 1, CaCl₂ → Ca²⁺ : Cl⁻ = 1 : 2, 전하 균형 유지)
- 입자 움직임: 브라운 운동(무작위 걸음). 속도에 끌림 + 정규분포 무작위 밀침(Ornstein–Uhlenbeck)을 매 장면 적용 → 방향이 계속 바뀌고 평균 빠르기는 일정, 오래 두면 액체 전체에 고르게 퍼짐
  - 용질은 비휘발성이라 수면 위로 나가지 않음, 벽·바닥·수면에서 튕김
  - 전해질은 화학식 1개가 녹는 자리에서 이온들이 함께 생겨 서로 흩어짐(해리)
  - 옅은 파란 점 = 용매 분자(개수 크게 줄임, 배경용)
  - 화면용 속도·크기: 실제 확산 계수·이온 반지름의 비율은 아님 (Cl⁻ 를 Na⁺·Ca²⁺ 보다 크게, 포도당을 요소보다 크게만 그림)
- 온도계 눈금은 용매마다 확대 기준이 다름
