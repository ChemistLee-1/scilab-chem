# 샤를 법칙: 온도와 부피 — `src/simulations/CharlesLaw.jsx`

- 단원: 물질과 에너지 Ⅰ-01 기체의 성질
- 성취기준: 12물에01-01
- 데이터: 기체 상수 R(1-2) ÷ 101.325 kPa/atm = 0.082057 L·atm/(mol·K), 몰질량은 CRC 원자량(1-11)으로 계산, 기체 목록은 `GASES`(He, Ne, Ar, N₂, O₂, CO₂)
- 디자인: 사용자 제공 HTML "샤를 법칙 시뮬레이션"의 기능을 사이트 공통 레이아웃으로 옮김 (다크 모드 색은 사이트 전체가 밝은 화면이라 넣지 않음)

## 기능
- 온도 100–600 K: 슬라이더 + °C·K 숫자 칸(서로 맞춰짐, Enter 또는 칸을 벗어나면 적용)
- 읽기: V, T, t, V/T, 입자 평균 속력 √(3RT/M)
- 일정 조건: 기체의 양 0.2–2 mol, 외부 압력 0.5–3 atm, 기체 종류(속력만 바뀜)
- 기록, 측정 오차(표준편차 % 직접 입력), 자동 측정(°C 시작·끝·간격, 최대 200회, 0.65초 뒤 기록, 중지 가능)
- 그래프: 가로축 t(°C)/T(K) 전환(°C 축은 −273.15 부터), 조건(n, P)별 색, 추세선(측정 범위 실선 + V = 0 까지 점선 연장)과 식·R²·V = 0 온도, 절대 영도 표시, **그래프 이미지(PNG) 저장**(SVG → 흰 바탕 2배 크기)
- 측정 데이터 표(행 삭제, 모두 지우기), **CSV 다운로드**: UTF-8 BOM, 열 = 번호, 기체, 몰수, 압력, t, T, V, V/T, 오차 표준편차. 파일 이름 `charles_law_YYYYMMDD_HHMM.csv`

## 계산·가정
- 이상 기체 V = nRT/P
- 입자 그림 40개 고정, 화면 속력 ∝ √(T/M) (N₂ 300 K 기준), 입자끼리 충돌 생략
- 실린더 눈금 최댓값 = 600 K 부피를 보기 좋은 수로 올림. 화면 온도는 천천히 따라감(화면용)
- 공통 부품 변경: `LineChart`에 `xTickValues`(가로축 눈금 직접 지정) 추가. 측정 표 스타일은 보일 법칙과 함께 `.data-panel`, `.data-table` 로 공유

## 검증값
- 1.00 mol, 1.00 atm, 0 °C → 22.414 L / 300 K → 24.617 L, N₂ rms 517 m/s(300 K)
- 오차 없이 자동 측정 0–300 °C: V = 0.082057 t + 22.4140, V = 0 일 때 t = −273.15 °C
- CSV BOM(EF BB BF), PNG 저장 확인
