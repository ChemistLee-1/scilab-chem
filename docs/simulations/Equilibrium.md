## 기능
- 반응식 **2NO₂(g) ⇌ N₂O₄(g)**, ΔH° = −55.3 kJ
- 온도 270–360 K(바로가기 5·25·70 °C), 부피 배율 0.5–1.8, 일시정지·초기화, NO₂ 30개 추가(농도 변화)
- NO₂·N₂O₄ 분자 수, 정·역반응 속도, Kc(CRC)·Q 와 진행 방향, 실제 농도(M), 분자 수 그래프 + 이론 평형값 점선
- 기체 색 안내(무색에 가까움 ~ 짙은 적갈색)

## 계산·가정
- 결합 방향 Kc(T) = R·T / Kp(해리), Kp(해리) = exp(−(ΔH° − TΔS°)/RT), 1 bar 기준, ΔH°·ΔS° 온도 무관 가정
- NO₂ 조각 1개 = 2×10⁻⁴ mol, 부피 배율 1 = 1 L, 처음 NO₂ 300개
- 정반응 속도 상수: 화면용 아레니우스(Ea 3 kJ/mol, A 0.1049). 역반응 속도 상수 kr = kf / (Kc · 조각 1개 농도) → 평형 조성이 CRC Kc 와 일치
- 결합은 NO₂ 끼리 부딪힐 때 일어나고, 결합 예약이 2 이상 밀리면 가장 가까운 NO₂ 끼리 붙여 평형 지연을 막음
- 이동은 프레임 속도와 무관(60 fps 기준 × dt)
- 분자 속력은 실제(√T)보다 과장해 T 에 비례
- 기체 색 진하기 ∝ [NO₂] (분자 수 ÷ 부피 배율)
- 용기 넓이 ∝ 부피 (1.8 일 때 바깥 점선 크기)
- 다크 모드 색은 넣지 않음(사이트 전체가 밝은 화면)
