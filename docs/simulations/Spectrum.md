# 원소의 선 스펙트럼 — `src/simulations/Spectrum.jsx`

- 단원: 통합과학1 Ⅱ-1-01 우주 초기에 형성된 원소
- 성취기준: 10통과1-02-01
- 데이터: `SPECTRA` (crc.js) — CRC Line Spectra of the Elements (10-1~), 중성 원자(I) 가시광선 선, Å → nm 환산
- 원소: H, He, Li, Na, Ne, Ca, Sr, Hg

## 기능
- 원소 스펙트럼: 원소 여러 개를 골라 방출/흡수 스펙트럼 비교
- 별빛 분석: 무작위 2~3개 원소의 흡수선이 섞인 "미지의 별"에서 원소 찾기

## 계산·가정
- 가로축 380–720 nm, 선 위치만 실측값. 선의 굵기와 밝기는 모두 같게 표시(CRC 세기 값은 표 파싱이 불확실해 쓰지 않음).
- 색은 `wavelengthToRGB` 근사 변환.
