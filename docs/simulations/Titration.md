## 기능
- 적정 곡선 탐구: 산 종류·농도(0.02–0.2 M) 선택, 이론 곡선과 중화점 표시
- 미지 시료 농도: 0.05–0.15 M 무작위, 학생이 계산한 농도 입력 → 오차 5% 이내면 정답
- 산 20.0 mL, NaOH 0.1 M, 뷰렛 0–50 mL, 콕 열기(1 mL/s) / 한 방울(0.05 mL) / 1 mL
- 입자 창: 삼각 플라스크 속 용액 전체를 확대해 입자의 움직임을 보여 줌
  - 넣은 NaOH 는 Na⁺ 와 OH⁻ 한 쌍으로 들어옴 → OH⁻ 가 H⁺(강산) 또는 HA 분자(약산)를 찾아가 반응해 물 분자가 생김(주황 고리로 표시)
  - Na⁺, Cl⁻ 같은 구경꾼 이온은 반응하지 않고 계속 떠돎 / 중화점 뒤에는 반응할 산이 없어 OH⁻ 가 쌓임
  - 반응식, 지금 단계(중화점 전·중화점·중화점 후), 입자별 그림 개수와 실제 mol 표시
  - 미지 시료 모드에서는 정답 전까지 산 관련 입자 개수를 '?' 로 숨김

## 계산·가정
- 전하 균형 [H⁺] + [Na⁺] = [OH⁻] + [A⁻] 를 이분법으로 풀이 (25 °C)
- 지시약 색: 변색 범위 안에서 산성색 → 염기성색 선형 혼합
- 적정 속도는 화면용
- 입자 1개 = 1.0 × 10⁻⁴ mol. 실제 양(mol)은 pH 와 같은 식에서 구함: [H⁺]·V, Kw/[H⁺]·V, Na⁺ = 0.1 M × V_NaOH, A⁻ = C·Ka/([H⁺]+Ka), HA = 나머지, 생성된 물 = 넣은 OH⁻ − 남은 OH⁻
- 그림 개수는 정수로 맞춤: 산 a개, NaOH b개 → 물 min(a,b), 남은 OH⁻ max(0, b−a), 강산의 H⁺ max(0, a−b), 약산의 H⁺ = round([H⁺]V ÷ 10⁻⁴) (보통 0–2개)
- 입자 창 용액 높이 ∝ 부피(1 mL = 6 px) → 같은 넓이 속 입자 수가 농도. 용매 물은 그리지 않음. H₃O⁺ 는 교과서처럼 H⁺ 로 표시
